## Why

构建一个「虚拟养成 + 情感陪伴」的移动应用，让用户在日常中感受到气运、能量、成长与奖励反馈。通过「主角系统」概念，将用户定位为人生主角，提供AI陪伴、任务系统、随机事件、抽卡收集等游戏化体验，满足30岁以下年轻群体对情绪陪伴和轻互动的需求。当前项目已有完整的需求文档和机制设计，需要将这些规划转化为可执行的开发任务。

## What Changes

- **核心系统实现**：宿主属性系统（气运、能量、心境、羁绊、专注）、货币经济系统（星尘、月华）、任务系统（A-H共8类任务类型）
- **陪伴者系统**：虚拟陪伴者形象展示、皮肤系统、技能卡收集与使用
- **互动系统**：AI陪聊、随机事件与分支抉择、签到系统
- **祈愿系统**：抽卡机制、卡池配置、保底规则、技能卡/皮肤/果实等奖励
- **配置驱动架构**：可扩展的配置表系统，支持任务、奖励、事件、卡池、皮肤等内容通过配置表扩展
- **多模态任务**：计时任务、健康数据任务、拍照识图任务、语音任务
- **界面实现**：5个主要Tab（主页、聊天、任务、祈愿、行囊）的完整UI布局与交互

## Capabilities

### New Capabilities

- `host-attributes`: 宿主属性系统，管理气运、能量、心境、羁绊、专注等属性，支持日界/周界刷新、buff修饰、数值夹逼
- `currency-economy`: 货币经济系统，管理星尘、月华、各类券的来源与消耗，支持经济自洽与审计
- `task-system`: 任务系统，支持8类任务（A自述、B计时、C健康数据、D对话、E签到、F拍照、G语音、H事件），包含状态机、验证机制、奖励分档
- `random-events`: 随机事件系统，支持事件配置、分支抉择、技能联动、权重计算、冷却机制
- `gacha-system`: 祈愿抽卡系统，支持多卡池、权重配置、保底规则、概率公示
- `companion-system`: 陪伴者系统，支持皮肤展示、换装、技能卡收集、陪伴者表现与属性联动
- `sign-in-system`: 签到系统，支持连续签到、月度里程碑、奖励派发
- `inventory-system`: 行囊系统，管理技能卡、果实、皮肤、碎片、道具的持有与使用
- `reward-dispatcher`: 统一奖励派发系统，所有奖励通过RewardBundle派发，保证可追溯与幂等
- `config-driven`: 配置驱动架构，支持任务、奖励、事件、卡池、皮肤、签到等通过YAML/JSON配置表扩展
- `ui-navigation`: 界面导航系统，实现5个Tab的主导航、各功能页面的布局与交互
- `ai-companion`: AI陪伴系统，支持LLM对话、人设提示词、任务上下文、情绪陪伴

## Impact

- **技术栈**：Kotlin Multiplatform (KMP)，共享业务逻辑，Android/iOS双端交付
- **依赖**：LLM API（AI对话）、健康数据API（可选）、相机/麦克风权限、支付API（后期）
- **数据持久化**：本地数据库或云端同步，存储宿主状态、钱包、行囊、任务实例、事件状态等
- **配置管理**：YAML/JSON配置表系统，支持热更新或版本迁移
- **UI框架**：Compose Multiplatform 或各端原生实现
- **合规要求**：抽奖概率公示、未成年人保护、隐私政策、健康数据权限说明、内容安全审核
