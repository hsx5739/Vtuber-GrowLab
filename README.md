# 主角系统

主角系统是一款围绕“陪伴式成长”设计的轻量互动应用原型，整合了首页角色互动、每日签到、任务推进、背包养成、商城兑换与抽卡收集等核心模块。应用强调角色陪伴感、资源联动和轻养成体验，用户可以通过日常签到和任务获取奖励，再将资源投入到背包、外观、商城与抽卡系统中，形成完整的循环。

## 功能概览

- 首页角色互动与台词切换
- 签到与任务奖励联动
- 背包、外观、技能、道具统一管理
- 商城资源兑换
- 抽卡与奖励回写背包
- 沉浸式深色视觉风格

## 项目结构

- `androidApp/`：Android 客户端界面与交互实现
- `shared/`：共享模型、配置与业务逻辑
- `docs/`：需求文档与开发拆解说明
- `resources/`：资源文件与素材

## 当前定位

该项目当前更偏向产品原型与功能联调版本，重点验证角色陪伴体验、签到任务链路、背包与商城抽卡联动，以及后续扩展为完整虚拟陪伴产品的可行性。
